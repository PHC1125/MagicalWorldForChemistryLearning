# 芙莉蓮的化學冒險：第一章

解壓縮後，開啟 `index.html` 即可遊玩。請保留同一資料夾中的 `冰川冒險素材/`；遊戲圖片都在這個資料夾內。

可自訂角色名稱與性別，並切換繁體中文或英文。進度、金幣、勳章和已兌換物品只儲存在目前裝置的瀏覽器本機，不會上傳或跨裝置同步；清除瀏覽器資料可能會刪除紀錄。所有化學操作皆為數位模擬，實際操作請依老師指示進行。

再次開啟時會先顯示冒險啟動畫面；已有存檔時按「繼續冒險」即可回到上次進度，金幣與勳章會保留。
